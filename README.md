# Tyau-Tyau 🐾

Telegram Mini App для собачников Ростова-на-Дону: кто гуляет прямо сейчас, поиск компании/пары для вязки («дог-тиндер»), локальная афиша встреч.

## Структура

- `backend/` — Express + Prisma (SQLite) + бот на grammY.
- `frontend/` — React + Vite + Tailwind + Leaflet.

## 1. Backend

```bash
cd backend
npm install
copy .env.example .env
```

Откройте `backend/.env` и впишите:
- `BOT_TOKEN` — токен вашего бота из @BotFather.
- `MINI_APP_URL` — куда бот будет отправлять кнопку «Открыть приложение». Для локальной разработки без реального Telegram можно оставить `http://localhost:5173`; для теста в настоящем Telegram сюда нужен публичный HTTPS-адрес (см. раздел про ngrok ниже).

Дальше:

```bash
npx prisma migrate dev --name init
npm run seed
npm run dev
```

Сервер поднимется на `http://localhost:4000`, а бот запустится через long polling (если указан `BOT_TOKEN`). Сид создаёт демо-пользователя, ~15 анкет собак, несколько активных точек на карте и одну встречу — чтобы сразу было что посмотреть.

## 2. Frontend

В новом терминале:

```bash
cd frontend
npm install
copy .env.example .env
npm run dev
```

Откроется `http://localhost:5173`. Vite-прокси сам перенаправляет `/api` и `/uploads` на backend (порт 4000), поэтому отдельно поднимать туннель для backend не нужно.

### Проверка без настоящего Telegram (сразу, локально)

Откройте `http://localhost:5173` в обычном браузере. Backend переходит в dev-режим авторизации и подставляет демо-пользователя (телеграм id `0`) — можно сразу кликать по всем 4 вкладкам, создать анкету, включить «Я на прогулке», сделать свайп (на анкете «Дружок» мэтч произойдёт сразу, он уже лайкнул вас в сид-данных) и создать встречу.

### Тёмная тема

Внутри Telegram тема подстраивается автоматически под клиент пользователя (светлый/тёмный режим Telegram). Вне Telegram (локальный браузер) приложение смотрит на системную тему устройства, а в правом верхнем углу есть кнопка-переключатель (☀️/🌙) — только для локальной проверки, в реальном Telegram она не отображается. Выбор запоминается в браузере (localStorage), так что переживёт перезагрузку страницы.

### Проверка внутри настоящего Telegram

Боту для Mini App нужен публичный HTTPS-адрес. Самый быстрый способ — один туннель на фронтенд (прокси уже достаёт backend через Vite):

```bash
ngrok http 5173
```

1. Скопируйте выданный `https://...ngrok-free.app` адрес.
2. Впишите его в `backend/.env` как `MINI_APP_URL` и перезапустите `npm run dev` в backend — бот будет отправлять кнопку именно на этот адрес.
3. В @BotFather: `/mybots` → ваш бот → `Bot Settings` → `Menu Button` (или `/newapp` для полноценного Mini App) → укажите тот же ngrok-адрес.
4. Напишите своему боту `/start` в Telegram — придёт кнопка «🐾 Открыть Tyau-Tyau», откроется приложение уже как настоящий Telegram Mini App (с вашим реальным Telegram-профилем вместо демо-пользователя).

Если хотите, чтобы кнопка «Позвать друзей» в афише собирала красивую диплинку `t.me/<bot>?startapp=...`, впишите username бота (без @) в `frontend/.env` как `VITE_BOT_USERNAME`.

## Дальше (не обязательно сейчас)

- Перейти с SQLite на Postgres для прод-окружения — поменять `DATABASE_URL` и провайдер в `prisma/schema.prisma`, остальной код не меняется.
- Задеплоить backend+frontend на постоянный хостинг (Railway/VPS/Vercel) вместо ngrok — тогда ссылка в `MINI_APP_URL` и у бота станет постоянной.
